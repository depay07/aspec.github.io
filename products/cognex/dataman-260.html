Fixed Barcode Reader

Cognex DataMan 260·262 시리즈 산업용 고정식 바코드 리더기

Cognex DataMan 260 시리즈는 Ethernet 기반 생산라인에 연결하는 소형 고정식 바코드 리더기입니다. 1D·2D 코드 판독과 PLC·MES 이력 연동을 위해 렌즈, 조명, 트리거와 통신 구성을 함께 선정합니다.

DataMan 260 견적·샘플 테스트 문의전화 상담

01 · Overview

제품 개요

DataMan 260은 조립 설비, 포장기와 컨베이어에서 코드를 읽고 생산 이력을 연결하는 공정에 적용할 수 있습니다. Ethernet 통신과 PoE 전원을 검토할 수 있어 리더기 연결 방식과 설비 배선 조건을 함께 맞춥니다.

DataMan 260과 262는 영상 해상도가 다릅니다. 넓은 판독 영역이나 작은 Data Matrix를 읽어야 한다면 코드 크기, WD, 렌즈와 함께 모델을 비교합니다. DPM 적용은 실제 마킹과 조명으로 테스트합니다.

Model Selection

DataMan 262S·262Q·262X 및 QL 모델 선정

DataMan 262는 DataMan 260 시리즈의 고해상도 모델입니다. DataMan 262S, 262Q, 262QL, 262X는 같은 해상도에서도 지원 판독 기능과 트리거 조건이 다릅니다. 읽을 코드와 생산속도를 기준으로 세부 모델을 비교하세요.

DataMan 262S·262QL·262Q·262X 모델 비교
모델명모델 표기해상도 (픽셀)판독 기능선정 기준
DataMan 262SDM262S1280 × 9601D·2D / IDQuick최대 취득 2 fps · 저속 트리거 판독
DataMan 262QLDM262QL1280 × 9601D / 1DMax1D 코드 전용 구성 · 2D 미지원
DataMan 262QDM262Q1280 × 9601D·2D / IDQuick인쇄 라벨의 QR·Data Matrix 판독 검토
DataMan 262XDM262X1280 × 9601D·2D / 2DMax 지원난독 2D·DPM 코드 샘플 테스트

기본 해상도인 DataMan 260S·260QL·260Q·260X는 752 × 480 픽셀입니다. DataMan 262 시리즈는 1280 × 960 픽셀로, 작은 코드나 넓은 FOV를 검토할 때 렌즈와 함께 비교합니다. 해상도만 높인다고 판독이 보장되지는 않으므로 초점·노출·조명 조건도 확인합니다.

DataMan 262S는 최대 취득 2 fps이며 Burst·Continuous 트리거 모드를 지원하지 않습니다. 262QL·262Q·262X의 최대 취득은 45 fps입니다. QL은 1D 코드 전용, Q는 일반 1D·2D 판독, X는 2DMax를 활용하는 난독 2D·DPM 판독을 검토하는 구성입니다. 실제 처리속도는 코드 품질과 설정으로 확인합니다.

262X-0540-P · DMR-262X-0540-P 품번 문의

262X-0540-P 또는 DMR-262X-0540-P처럼 전체 품번으로 제품을 찾으신다면 본체 라벨이나 견적서의 품번을 함께 보내주세요. DataMan 262X의 판독 기능과 별도로 렌즈·조명·케이블 및 전원 구성을 확인해 기존 설비와의 호환성을 검토합니다.

생산라인의 리더기 판독 결과를 PLC나 PC로 전달합니다. 장비의 통신 규격과 결과 데이터 형식을 먼저 확인합니다.

설치 방향과 광학 유연성

08 · FAQ

제품 선정 FAQ

DataMan 262Q와 262X는 어떻게 선택하나요?

262Q는 IDQuick 기반의 일반 2D 코드 판독을, 262X는 2DMax를 활용하는 난독 2D·DPM 코드 판독을 검토합니다. 코드가 금속 각인인지 인쇄 라벨인지, 셀 크기와 표면 반사가 어떤지에 따라 실제 샘플로 비교합니다.

DataMan 260과 262는 무엇이 다른가요?

260은 752 × 480, 262는 1280 × 960 픽셀입니다. 해상도가 높아도 렌즈, 코드 크기와 조명 조건이 맞지 않으면 판독이 어렵기 때문에 샘플 영상으로 비교합니다.

PoE만으로 사용할 수 있나요?

공식 사양상 PoE Class 1 전원 구성을 지원합니다. PoE 전원 장치, 케이블과 I/O 사용 조건을 확인해 전체 배선을 구성합니다.

PLC와 MES에 판독 데이터를 보낼 수 있나요?

Ethernet 기반으로 결과를 전달하고 PLC 또는 중계 프로그램으로 MES와 연결할 수 있습니다. 기존 장비의 지원 통신 방식, 데이터 형식과 No Read 처리 조건을 확인합니다.
